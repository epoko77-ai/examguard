# 세 가지 탐지 개선 제안의 현재 상태

| 제안 | 구현 상태 | 남은 작업 |
| --- | --- | --- |
| 제조사 코드 + UUID + 광고 바이트 정밀 필터 | **외부 v2 입력용 복합 규칙 엔진 구현.** 같은 광고의 세 조건을 AND로 비교하고 회사 ID만 일치한 결과를 분리. 마스크·출처·다중 후보·보고서 지원 | 실기기 검증 규칙, Android/ESP32 변환 어댑터, 실제 오탐·미탐 비교 |
| BLE + Wi-Fi P2P 트래픽 결합 | **미구현.** 일반 Web Bluetooth API는 주변 Wi-Fi 트래픽을 제공하지 않음 | 적절한 외부 수신기/네이티브 관측 수단, 동일 기기 연계 근거, 촬영과 다른 전송을 구분하는 실험 |
| LED가 꺼져도 물리적 카메라 홀을 찾는 YOLO | **미구현.** 현재 B 모드는 카메라 확대·필터를 통한 육안 보조, C 모드는 CLIP 기반 사진 후보 검색 | 실제 렌즈 홀/일반 나사·장식 구분 데이터와 라벨, 모델·가중치, 다양한 조명·기종의 독립 평가 |

현재 개선을 **기존 앱보다 정확하다**, **실제 촬영을 판별한다**, **LED 가림을 무력화했다**고 소개하지 않습니다. 회사 ID만 일치한 기기를 후보로 올리지 않는 동작은 테스트했지만, 실제 기기 데이터에 대한 성능 검증은 별도입니다. Wi-Fi 전송이 관측되어도 업데이트·파일 복사 등일 수 있으므로 촬영 증거와 같지 않습니다.

Nearby Glasses는 회사 ID 외에 이름·일부 UUID도 사용하고, MetaDetect도 여러 단서를 사용합니다. 기존 프로젝트 전체를 회사 ID만 쓰는 도구로 단정하지 않습니다. ExamGuard의 현재 차별점은 **입력 규칙의 복합 조건·근거를 표시하고 시험장 점검과 실물 확인까지 연결한 것**입니다. [참고 프로젝트와 연결 범위](INTEGRATIONS.md) · [복합 규칙 계약](SIGNATURES.md)
