# 사진 대조 기능

## 목적과 현재 데이터

안경 사진에 가까운 도감 카드를 찾아 감독관이 볼 범위를 줄입니다. CLIP은 일반 이미지 표현 모델이며 스마트안경 전용 식별기로 학습하거나 미세 조정하지 않았습니다. 카메라 구멍·충전 핀을 검출하거나 치수를 재지 않습니다.

- 모델: [`Xenova/clip-vit-base-patch32`](https://huggingface.co/Xenova/clip-vit-base-patch32), MIT
- 리비전: `6b7c523703ae26e39be4b03774966f8571c7f523`
- ONNX `vision_model_quantized.onnx`, q8, 약 89.1 MB
- 참조: 스마트안경 5개 제품군 + 일반 안경 1개 비교군, 총 9개 이미지. [개별 출처·해시](reference-sources.json)
- 사용자가 사진을 선택하고 명시적으로 대조를 실행해야 모델을 다운로드합니다.

## 처리 과정

1. 사용자가 고른 JPG·PNG·WebP를 최대 1,536픽셀로 줄여 메모리에 보관합니다. 12 MB, 4,000만 화소를 초과하거나 가로·세로 128픽셀 미만이면 거부합니다.
2. 사용자가 조정한 영역을 흰색 여백이 있는 512×512 캔버스로 만듭니다.
3. CLIP 프로세서가 모델 입력을 만들고 q8 vision projection이 512차원 벡터를 만듭니다.
4. L2 정규화한 참조와 코사인 유사도를 계산합니다. 기종별 가장 높은 참조 점수로 정렬하여 상위 3개 카드를 보여줍니다.
5. 사용자가 부품 위치와 공식 자료를 실물에 대조합니다. 사진과 결과는 보고서에 넣지 않습니다.

유사도는 확률이 아닙니다. UI는 숫자 점수를 표시하지 않습니다. 최고 유사도 0.55 미만이면 재촬영 안내, 1·2위 차이 0.04 미만이면 후보 차이가 작다는 안내를 표시합니다. 이 값들은 UX용 임시 휴리스틱이며 검증된 결정 임계값이 아닙니다. 높은 점수에서도 도감에 없는 제품일 수 있습니다.

## 한계와 검증

참조 수가 매우 작고 제품 사진 중심입니다. 촬영 각도·배경·프레임 색·조명에 민감하며 일반 안경과 오디오 안경처럼 닮은 형태를 혼동할 수 있습니다. 부품이 작게 찍히면 CLIP의 전체 형태 표현만으로 구별하기 어렵습니다. 일반 안경 카드가 1위여도 전자 기능이 없다는 판정이 아닙니다. 얼굴 인식과 소유자 확인은 수행하지 않습니다.

단위 테스트는 참조 벡터의 차원·정규화·출처·도감 매핑을 검사합니다. 브라우저 테스트는 실제 WASM 모델을 실행하고 참조 사진 크롭의 후보·오프라인 재실행·업로드 요청 부재를 확인합니다. 참조와 같은 사진을 쓴 검사는 통합 회귀 검사입니다. 별도 현장 검증 세트에 대한 Top-1/Top-3 정확도, 오탐률, 미탐률은 아직 측정하지 않았습니다.

후속 검증에는 서로 다른 촬영자·장소·각도의 독립 사진, 다양한 일반 안경, 미등록 제품, 흐린 사진·안경이 없는 사진을 포함해야 합니다. 제품 인스턴스 단위로 학습/참조와 평가를 분리하고 기종별 Top-3 및 부적절한 확신 발생률을 공개해야 합니다. 이 평가 전까지 자동 적발·기종 확정에 쓰지 않습니다.

## 재현

```sh
npm ci
npm run setup:models
npm run build:references
npm test
```

참조 생성 스크립트는 원본을 `.local/reference-images/`에 받고 출처 해시를 검사합니다. 원본이 변경되면 중단하므로 사람이 이미지를 확인한 뒤 메타데이터를 갱신해야 합니다. 앱에는 벡터만 포함하며 제조사 이미지는 배포하지 않습니다. 다른 실행 엔진의 부동소수점 차이로 마지막 자릿수는 달라질 수 있습니다.

브라우저에서는 WASM 단일 스레드를 사용하여 별도의 COOP/COEP 헤더 없이 동작하도록 설계했습니다. 취소/초기화 시 Worker를 종료하여 모델과 사진 작업을 해제합니다. 메모리가 부족하거나 지원하지 않는 브라우저에서는 오류를 안내하고 수동 도감을 계속 사용할 수 있습니다.
