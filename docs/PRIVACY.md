# 데이터 흐름

사진·카메라 프레임은 Canvas와 Worker 메모리에서만 처리합니다. 업로드 API, 클라우드 AI 호출, 분석 추적, 로그인 기능이 없습니다. 카메라는 음성을 요청하지 않습니다. 사진 메타데이터를 읽거나 보고서에 넣지 않습니다.

BLE는 사용자가 선택한 기기의 이름과 선택 시각을 기록합니다. 브라우저 기기 ID는 같은 세션 내 중복 선택 구분용 Map에만 쓰고 내보내지 않습니다. 연결/GATT 읽기나 강제 페어링은 하지 않습니다. 사용자 사진에서 얼굴·이름·소유자를 식별하지 않습니다.

외부 수신기 JSON과 수동 관찰은 메모리에서만 유지합니다. 새 점검·새로고침으로 기록이 사라집니다. 앱의 새 점검은 사진과 결과도 지웁니다. 내려받은 JSON은 사용자가 직접 관리하며 기기 이름·시각·확인 구역이 포함될 수 있습니다. 기여 이슈에 현장 기록을 그대로 올리지 마세요.

Service Worker의 Cache Storage에는 같은 출처의 앱 코드, 도식, 참조 벡터, 모델 파일만 저장합니다. 기록·사진은 캐시에 넣지 않습니다. 기본 앱 파일은 첫 방문에, 모델/실행 엔진은 첫 검색에 다운로드합니다. 모델 캐시도 브라우저의 사이트 데이터 지우기로 제거할 수 있습니다.

모델 설치 스크립트는 개발/CI에서 Hugging Face에 접속합니다. 운영 웹앱은 같은 호스팅 출처에서만 파일을 받습니다. 기본 CSP는 다른 출처의 연결을 제한합니다. 공식 제품 링크를 직접 열면 해당 사이트로 이동합니다. GitHub Pages 등 호스팅 제공자의 IP·접속 로그는 해당 서비스 정책에 따르며 “어떤 네트워크 요청도 없다”는 뜻은 아닙니다.
